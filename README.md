# Bubble Tanks: Reborn

## An open-source recreation and extension of the discontinued Flash game "Bubble Tanks 3" on Godot Engine.

Controls
- WASD or arrow keys to move.
- LMB (or Space) to shoot.
- F to activate and deactivate freecam.
- YGHJ to move freecam.
- CTRL to not move a part when selected.
